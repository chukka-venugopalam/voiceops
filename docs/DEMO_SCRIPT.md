# 2-minute demo (max) - what to say and show

Run `python demo_server.py`, open http://localhost:8000, record the screen WITH sound (Windows: Win+G; macOS: Cmd+Shift+5; or OBS).
The page shows the heard text, the reply, the decision and the policy sections used - leave them visible.

| Time | You say (customer) | What the viewer should notice |
|---|---|---|
| 0:00-0:10 | (voice-over) "ZentroMart support agent: answers from policy documents, verifies the caller, and speaks." | one line only |
| 0:10-0:25 | "Hello, mujhe order ke baare mein help chahiye." | agent says it is an AI assistant and asks for the order ID |
| 0:25-0:45 | "Order number hai 1859 9253." then "Last four digits 4265 hain." | order lookup, then verification before any detail |
| 0:45-1:10 | "Kya main Kaafi Running Sneakers return kar sakti hoon?" | answer with the date 27 October 2026 and sources RET-2 shown |
| 1:10-1:25 | "Aur refund kitne din mein aayega?" | follow-up understood without repeating: wallet refund is instant |
| 1:25-1:50 | "Can I speak to a person?" (or a question the documents do not cover) | ticket created, colleague will contact; or an honest "I don't have that information" |
| 1:50-2:00 | (voice-over) "Dates and rules are computed in code; the LLM only words answers from the documents." | stop at 2:00 |

Tips: rehearse once (cached replies make the second run instant); speak clearly near the mic; keep the recording under 2:00; export as `demo.mp4`.
